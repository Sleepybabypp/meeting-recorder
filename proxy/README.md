# ตั้งตัวกลางเก็บคีย์ (ทำครั้งเดียว ประมาณ 5 นาที)

เมื่อตั้งเสร็จ คนที่เปิดแอปใช้ AI ได้ทันทีโดยไม่ต้องใส่คีย์ คีย์ Gemini จะเก็บอยู่ใน Cloudflare เท่านั้น ไม่อยู่ในโค้ดของแอปและไม่อยู่ใน GitHub

## ขั้นตอน

1. ไปที่ dash.cloudflare.com แล้วสมัครหรือเข้าสู่ระบบ (แพ็กเกจฟรีใช้ได้ วันละ 100,000 คำขอ)
2. เมนูซ้าย เลือก **Workers & Pages** แล้วกด **Create** จากนั้นเลือก **Create Worker**
3. ตั้งชื่อ เช่น `chy-meeting` แล้วกด **Deploy**
4. กด **Edit code** ลบโค้ดตัวอย่างออกให้หมด วางโค้ดทั้งหมดจากไฟล์ `worker.js` แล้วกด **Deploy**
5. กลับไปหน้าของ Worker เลือก **Settings** แล้วไปที่ **Variables and Secrets** กด **Add**
   - Type: **Secret**
   - Variable name: `GEMINI_KEY`
   - Value: วางคีย์ Gemini ของคุณ
   - กด **Deploy**
6. คัดลอกที่อยู่ของ Worker เช่น `https://chy-meeting.xxxx.workers.dev` แล้วส่งให้ผู้พัฒนาใส่ในแอป ที่อยู่นี้ไม่ใช่ความลับ ส่งต่อได้

## สิ่งที่ควรรู้

- ทุกคนที่ใช้แอปจะใช้โควตาจากคีย์เดียวกัน คีย์ฟรีมีโควตาจำกัดต่อนาทีและต่อวัน ถ้ามีคนใช้เยอะ ต้องเปิดการจ่ายเงินใน Google AI Studio
- ถ้าใช้คีย์ฟรี Google อาจนำข้อมูลไปพัฒนาระบบ ไม่ควรใช้กับประชุมที่เป็นความลับ
- ตัวกลางนี้รับคำขอเฉพาะจากเว็บของแอป (เพิ่มเว็บอื่นได้ที่ `ALLOWED_ORIGINS` ในโค้ด) และจำกัดไว้ที่ 90 ครั้งต่อนาทีต่อเครื่อง วิธีนี้กันการใช้แบบทั่วไปได้ แต่คนที่ตั้งใจจริงยังเลี่ยงได้ จึงควรตั้งงบหรือการแจ้งเตือนการใช้งานใน Google AI Studio ไว้ด้วย
- ถ้าคีย์หลุดหรืออยากเปลี่ยนคีย์ ให้แก้ค่า `GEMINI_KEY` ใน Cloudflare ได้ทันที ไม่ต้องแก้แอป
